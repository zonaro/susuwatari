Susuwatari

Interactive Wallpaper for Lively Wallpaper & Wallpaper Engine

Choose your preferred platform to use Susuwatari:

🎮 Steam Workshop - Wallpaper Engine

🎮 How to install via Wallpaper Engine (Steam Workshop):

  1. Have Wallpaper Engine installed on Steam
  2. Click the "🎮 Steam Workshop" button above
  3. Click "Subscribe" on the Workshop page
  4. Open Wallpaper Engine
  5. Go to the "Workshop" tab
  6. Find Susuwatari in "Subscribed" and activate it
  7. Configure the properties as desired
  8. Enjoy your interactive Susuwatari! 🎉

📋 How to install on Lively Wallpaper:

  1. Download the Susuwatari.zip file by clicking the button above
  2. Open Lively Wallpaper
  3. Click "Add Wallpaper" or "+"
  4. Navigate to the folder where you downloaded the file and select Susuwatari.zip
  5. Configure the properties as desired
  6. Enjoy your interactive Susuwatari! 🎉
