# Background Images Folder

Esta pasta contém imagens de fundo para o Lively Wallpaper.

## Como Usar (Lively Wallpaper)

1. **Folder Dropdown**: Use o controle "Background Image File" nas configurações
2. **FilePicker**: Clique no botão de seleção de arquivo para adicionar novas imagens
3. **URL Input**: Use o campo "Background Image URL" apenas para URLs da web (http://, https://)

## Formatos Suportados
- JPG/JPEG, PNG, GIF, BMP, WebP

## Importante
- O campo "Background Image URL" agora aceita APENAS URLs da web
- Para arquivos locais, use o Folder Dropdown ou FilePicker
- Caminhos de arquivo locais não são mais aceitos no campo de texto
